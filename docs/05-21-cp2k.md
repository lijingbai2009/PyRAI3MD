The cp2k section configures the cp2k skill, which runs DFT and TDDFPT (linear-response) calculations with CP2K/Quickstep, for molecular and fully periodic systems alike. It is read when cp2k appears in the theory queue of &CONTROL and is spelled &CP2K in the classic input, cp2k in YAML and agent JSON. The section is optional; an absent section runs the skill on the defaults listed below.

The keys are grouped as the run arm and program paths, the method and model, the iteration and output controls, and finally the state, cell and environment keys the framework forwards from &MOLECULE and &MD. Those last keys are documented once in [Section 5.2](05-02-system-molecule.html) and repeat here only so the section reads in full. [Section 4](04-input-files-and-conventions.html) shows the same section in the three input carriers.

The skill exposes the following profiles. A profile fixes the method and the set of properties a calculation returns.

| Profile | Capability | Method |
| :--- | :--- | :--- |
| dft_energy | energy | dft |
| dft_gradient | gradient | dft |
| dft_opt_min | geometry_optimization | dft |
| dft_md | abinitio_dynamics | dft |
| tddft_energy | energy | tddft |
| tddft_gradient | gradient | tddft |
| tddft_transition_dipole | transition_dipole | tddft |
| tddft_opt_min | geometry_optimization | tddft |
| tddft_md | abinitio_dynamics | tddft |

Full descriptions for all available keywords are summarized below.

**execution_mode** - Chooses the run arm. local starts CP2K as a subprocess of the framework; slurm writes a batch script and submits it with sbatch. The arm changes only the launcher, because both arms run the same generated input.

**shell** - Sets the skill-level shell commands, one command per line, copied verbatim into the run or batch script before the CP2K call. It carries the module loads and exports a site needs before CP2K starts; the framework environment section is not forwarded here.

**project** - Sets the stem of the run artifacts. The CP2K input, log and coordinate file carry it, for example &lt;project&gt;.inp, &lt;project&gt;.log and &lt;project&gt;.xyz. The classic input spells the same value cp2k_project, and the two are kept equal.

**cp2k_project** - Sets the project stem through the classic-input spelling. It is copied into project, which is the single value used for &lt;project&gt;.inp, &lt;project&gt;.log and the {project}-pos-1.xyz and {project}-force-1_0.xyz files.

**cp2k_path** - Sets the CP2K installation directory CP2K_HOME. The run script exports CP2K_HOME, resolves the executable from it when cp2k_exe is empty, and puts OMP_NUM_THREADS on the environment. Validation refuses a directory that does not exist, so a misspelt installation is reported before a job is written. The value is the same one the toolchain build exports, which is what makes a run script portable between the demo and the local installation.

**cp2k_exe** - Sets the CP2K executable. An empty value resolves to $CP2K_HOME/exe/local/cp2k.psmp; an MPI build is expected because the run starts through mpirun.

**setup_script** - Names a toolchain setup script that is sourced before the calculation starts, for example the install/setup file of a CP2K build. An empty value sources nothing.

**keep_tmp** - Keeps the calculation directory when 1, and deletes it once the results have been parsed when 0. A kept directory holds the input, the log, the force and trajectory files, and the strain directories of a numerical stress run.

**thread** - Sets the OpenMP threads of one rank, exported as OMP_NUM_THREADS. cp2k_thread is the framework spelling, and a written pair folds to the larger value so neither spelling can shrink the request.

**cp2k_thread** - Sets the OpenMP thread count through the spelling the framework forwards from the &CP2K section. It is folded into thread, and the larger of the pair is what the run script exports.

**nproc** - Sets the number of MPI ranks, passed to mpirun as -n. cp2k_nproc is the framework spelling, and the larger value of the pair is used.

**cp2k_nproc** - Sets the MPI rank count through the framework spelling. It folds into nproc, the larger value winning, so a request made in either spelling is honoured.

**slurm_time** - Sets the wall-clock limit of the submitted job in hh:mm:ss. It is read only when execution_mode is slurm.

**slurm_partition** - Sets the scheduler partition of the submitted job. An empty value writes no partition directive, so the cluster default answers.

**slurm_ntasks** - Sets the number of tasks of the submitted job, which the batch template forwards as the MPI rank count.

**slurm_memory** - Sets the memory per node of the submitted job in MB.

**slurm_command** - Sets the submission command of the batch script, for example sbatch or a site wrapper. An empty value uses the default.

**profile** - Selects the calculation profile, which fixes the CP2K RUN_TYPE chain. The nine values are dft_energy, dft_gradient, dft_opt_min, dft_md, tddft_energy, tddft_gradient, tddft_transition_dipole, tddft_opt_min and tddft_md; a profile that does not belong to the chosen method is refused.

**method** - Selects the electronic-structure method, dft for the ground state or tddft for linear-response excited states. The method decides which tasks exist: both carry energy, gradient, geometry optimization and ab-initio dynamics, tddft adds transition dipoles, and neither carries nonadiabatic coupling, spin-orbit coupling, dipoles or frequencies. A profile has to belong to the chosen method, so dft_gradient with method tddft is refused rather than silently rewritten.

**functional** - Selects the exchange-correlation functional, pbe or pbe0 only. pbe is written as a PBE functional section. pbe0 is assembled from the same section with SCALE_X 0.75 plus a Hartree-Fock section with fraction 0.25, the layout the verified bulk demo uses. Any other name raises an unsupported-functional error, and the dispersion reference functional follows this value.

**cutoff** - Sets the plane-wave cutoff of the Quickstep grid in Ry, written as &MGRID CUTOFF. Both cutoffs are always written explicitly, so a CP2K default never decides the grid. The value must be positive; 400 Ry is the shipped default and what the demo inputs use.

**ref_cutoff** - Sets the refined-grid cutoff in Ry, written as &MGRID REL_CUTOFF. Raising it widens the region in which a basis function is mapped onto the reference grid, which is the usual remedy for a noisy force or a slowly converging SCF. The value must be positive, and 50 Ry is the default.

**basis_file** - Lists the CP2K basis-set library files, written one BASIS_SET_FILE_NAME line each. The default is BASIS_MOLOPT; a second entry such as BASIS_ADMM_UUZ is added for an ADMM run.

**potential_file** - Lists the pseudopotential library files, written one POTENTIAL_FILE_NAME line each. The default is POTENTIAL.

**auxiliary_basis_file** - Lists the auxiliary-basis library files of an ADMM run, for example BASIS_ADMM_UUZ. The list is independent of whether ADMM is active, which the element-level auxiliary_basis mapping decides.

**basis** - Sets the basis set per element as a name-to-keyword mapping, for example C: DZVP-MOLOPT-SR-GTH-q4. Normalization fills every element the mapping leaves out with DZVP-MOLOPT-SR-GTH plus the valence-electron suffix of that element, and a MOLOPT entry given here wins over the filled value. Elements outside the valence table fall back to the unsuffixed name and rely on the override. The names are resolved by CP2K from the library files named in basis_file.

**potential** - Sets the pseudopotential per element, for example O: GTH-PBE-q6. Every element the mapping leaves out is filled with GTH-PBE, and an explicit entry takes priority. The potential has to come from the library file named in potential_file, which defaults to POTENTIAL.

**auxiliary_basis** - Sets the auxiliary basis per element and, by being non-empty, switches ADMM on: the input gains an auxiliary-density-matrix method with basis projection and an AUX_FIT basis set per kind, and a TDDFPT run adds a no-purification method because ADMM and the response solver do not combine otherwise. Missing elements are filled with admm-dzp plus the valence suffix. An empty mapping leaves ADMM off and the run is a plain Quickstep calculation.

**dispersion** - Adds a Grimme dispersion correction through &VDW_POTENTIAL. d3 writes DFTD3 and d3bj writes DFTD3(BJ); an empty value or none omits the section, which is the default. The reference functional of the correction always follows the active functional, so pbe0 with d3 writes PBE0, and an unknown token is refused.

**dipole_correction** - Turns on the slab dipole correction, written as SURF_DIP .TRUE. with SURF_DIP_DIR Z. It requires a periodic slab whose normal is the z axis; a non-periodic cell, a tilted cell, and a numerical full-strain stress request are refused.

**tddft_dipole_form** - Selects the gauge of the transition dipole moments, length or velocity, written as DIPOLE_FORM in the TDDFPT section. The default is length.

**tddft_maxiter** - Sets the maximum number of TDDFPT iterations, written as MAX_ITER in the TDDFPT block of the CP2K input.

**tddft_converge** - Sets the TDDFPT eigenvalue convergence threshold. The default 1e-5 is the value the skill convergence table uses for the response solver.

**nstate** - Sets the number of electronic states of the run. The TDDFPT root count is derived from it when tddft_nstates is unset, and every target state index has to stay below it.

**stress** - Requests the whole-system stress tensor. The result arrives in stress_tensor as an (nstate, 3, 3) array, tensile-positive, in GPa, and the framework converts it centrally to Hartree/Bohr^3. The framework planning route injects the request for NPT dynamics or a variable-cell optimization, while a standalone test input may set it directly. The request is orthogonal to the profile: the tensor keywords are added on top of the active profile and the parser reads the block non-blocking, so an absent tensor is zeros rather than a failed step. The best route for a ground state is the analytical one, because the engine already reports that tensor.

**stress_method** - Selects the stress route. analytical asks CP2K for its STRESS_TENSOR ANALYTICAL, the ground-state tensor the engine prints; num differentiates the energy over an external strain scan and sends no stress keyword at all. An empty value is resolved from the method, tddft to num and dft to analytical.

**stress_delta** - Sets the dimensionless strain step of the numerical stress route. A value outside the interval (0, 1e-2] is refused, and 1e-4 to 1e-3 is the recommended starting range.

**stress_scope** - Selects the strain directions the numerical route samples. full perturbs the six independent tensor components, twelve single points; iso dilates the cell uniformly in two points and reports the result on the diagonal.

**scf_converge** - Sets the SCF energy convergence threshold in Hartree, written as EPS_SCF in &SCF. The default is 1e-6.

**scf_maxit** - Sets the maximum number of SCF cycles, written as MAX_SCF in &SCF.

**opt_converge** - Carries the convergence verdict of the internal geometry optimization back to the framework. The parser fills it from the GEO_OPT block, and false means the optimization stopped before it converged.

**opt_maxit** - Sets the maximum number of geometry-optimization steps, written as MAX_ITER in the GEO_OPT block of &MOTION.

**md_nstep** - Sets the number of steps of a standalone MD profile, written into &MOTION &MD. Framework-driven dynamics does not read it, because there the framework steps through the gradient profile.

**md_timestep** - Sets the timestep of a standalone MD profile in fs. Like md_nstep it belongs to the skill-driven MD profiles only.

**md_ensemble** - Selects the ensemble of a standalone MD profile, NVE or NVT. NVT uses the CSVR thermostat, whose temperature is the framework temperature key.

**tddft_nstates** - Sets the number of TDDFPT roots per spin manifold. Zero leaves the count to the normalization, which derives it from nstate, the target states and the triplet count.

**nsing_root** - Counts the excited singlet roots of the state ladder. The normalization fills it from the state spins, and the TDDFPT block solves that many singlet roots.

**ntrip_root** - Counts the triplet states of the ladder. A positive value switches RKS_TRIPLETS on, so the TDDFPT block solves triplet roots as well as singlet roots.

**ir_width** - Sets the FWHM broadening in cm-1 that an IR spectrum drawn from a frequency run would use. It is carried for the property pipeline; the CP2K skill computes no frequencies in this version. This keyword is accepted but has no effect in v3.0.0.

**ir_scale** - Sets the scale factor applied to harmonic frequencies before an IR spectrum is drawn; 1.0 leaves computed wavenumbers unscaled. The CP2K skill computes no frequencies in this version. This keyword is accepted but has no effect in v3.0.0.

**uv_width** - Sets the FWHM broadening in cm-1 of an absorption spectrum built from excitation energies. The skill reports transition dipoles and oscillator strengths but draws no spectrum. This keyword is accepted but has no effect in v3.0.0.

**nics_ring** - Lists the ring atom indices of a NICS calculation. The default [0] is the unset marker, and no CP2K run consumes the key in this version, which computes no shielding tensors. This keyword is accepted but has no effect in v3.0.0.

**nics_scan** - Lists the probe positions in Angstrom of a NICS height scan. The default [0.0] is the unset marker, and no CP2K run consumes the key in this version. This keyword is accepted but has no effect in v3.0.0.

**charges** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**multiplicity** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**ci** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**spin** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**coupling** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**target_states** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**verbose** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**solvent** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**temperature** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**shape** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

**factor** - Framework keyword; the skill receives it from &MOLECULE and &MD. See [Section 5.2](05-02-system-molecule.html).

The skill runs nine profiles and nothing else. dft_energy, dft_gradient, dft_opt_min and dft_md cover the ground state; tddft_energy, tddft_gradient, tddft_transition_dipole, tddft_opt_min and tddft_md cover the excited state. Framework-driven dynamics does not use the \*_md profiles: with driver main the framework propagates and asks for dft_gradient one step at a time, and an md jobtype handed to the skill itself is refused because it would resolve to a single point on a frozen geometry.

Full three-dimensional periodicity is supported through pbc and lattice_vector. Partial periodicity such as [1, 1, 0] is refused because the low-dimensional electrostatics mapping is not defined in this version, and a periodic run needs a non-singular lattice. Without a cell the skill builds a vacuum box and solves it with the WAVELET Poisson solver, which is what a molecular run uses.

Requests the emitted input cannot honour are refused instead of approximated: a multiplicity other than 1, because the SCF block carries no unrestricted keyword; a functional other than pbe or pbe0; a triplet state row under method dft; an analytical stress tensor under method tddft, which CP2K aborts with "Stress Tensor not available for TDDFT calculations"; and the slab dipole correction for a non-periodic or tilted cell, or together with a numerical full-strain stress request.

The skill computes no nonadiabatic coupling, no spin-orbit coupling and no frequencies, so those jobtype tokens are refused rather than returned as zeros. A numerical stress scan never relaxes its strain points, so it reports the instantaneous stress of the configuration handed in, and a point whose state order changes fails the tensor by name because character-based state tracking is not implemented. A non-zero CP2K return code raises immediately instead of masking the failure.
